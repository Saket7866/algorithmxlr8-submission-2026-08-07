# Two Sum

**Difficulty:** `Easy`

## Problem

Given an array of integers nums and an integer target, return the indices of the two numbers that add up to target. Exactly one valid answer is guaranteed to exist, and you may not use the same element twice.

Read n and target on the first line of standard input, then n space-separated integers on the second line. Print the two indices, space-separated, in the order they are found (the lower index first).

## Examples

### Example 1

**Input**
```
4 9
2 7 11 15
```
**Output**
```
0 1
```

**Explanation:** nums[0] + nums[1] = 2 + 7 = 9.

### Example 2

**Input**
```
3 6
3 2 4
```
**Output**
```
1 2
```

**Explanation:** nums[1] + nums[2] = 2 + 4 = 6.

### Example 3

**Input**
```
2 6
3 3
```
**Output**
```
0 1
```

**Explanation:** nums[0] + nums[1] = 3 + 3 = 6.
